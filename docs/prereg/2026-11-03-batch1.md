# Pre-registration: strategy batch 1 (2026-11-03)

Written and committed **before** any batch-1 result is computed. Judged by the three-tier
framework (`docs/prereg/2026-11-03-decision-framework.md`). Scoping:
`docs/2026-11-03-strategy-scoping.md`.

## Shared setup

- **Universe:** the six coins that pass the spread/volume screen on Binance.US today:
  BTC, ETH, SOL, XRP, DOGE, LINK (USDT pairs, Binance.US bars). A coin enters a test once
  it has the history the rule needs (XRP bars start 2023-07-14).
- **Long or flat only.** Weights per coin are ≥ 0 and sum to ≤ 1 (no leverage). The
  weights *are* the planned live sizing: a fraction of one budget.
- **Execution model:** weights decided on a bar's close, filled at the next bar's open.
  Cost per side on every weight change: BTC 5, ETH 5, SOL 6, XRP 5, DOGE 7, LINK 8 bps;
  ×3 on bars in the top decile of trailing 24h realized volatility (threshold from
  in-sample bars only).
- **In-sample:** 2022-01 → 2024-12. Walk-forward with 12-month train, 3-month test,
  3-month step, test folds 2023Q1–2024Q4; each fold uses the best train-window net Sharpe.
- **Final parameters:** best net Sharpe on 2024. **Out-of-sample:** 2025-01-01 →
  2026-11-01, run once with frozen parameters.
- **Trials added:** 9 + 8 + 3 + 3 = 23 (running total 337).

## Strategy 1: daily trend, volatility-scaled (`trend`)

Daily bars. For each coin: long if the trailing L-day return is > 0, else flat. Weight
when long = (1/6) × min(1, target / realized vol), where realized vol is the annualized
standard deviation of the last 30 daily returns.
Grid: L ∈ {20, 50, 100} × target ∈ {0.4, 0.6, unscaled} → 9 trials.

## Strategy 2: momentum rotation (`rotation`)

Daily bars, rebalanced weekly at Monday 00:00 UTC. Rank coins by trailing L-day return;
hold the top k at weight 1/k each, but only coins whose L-day return is > 0 (others stay
in cash). Grid: L ∈ {7, 14, 28, 56} × k ∈ {2, 3} → 8 trials.

## Strategy 3: volatility-sized breakout (`breakout_vol`) — exploratory only

1h bars. Signals are the already frozen breakout selections (BTC/ETH/SOL from the Phase 2
study, XRP/DOGE/LINK from the alt-coin study). Weight when in a position =
(1/6) × min(1, target / realized vol over the last 720 hourly returns, annualized).
Grid: target ∈ {0.4, 0.6, 0.8} → 3 trials.
**Caveat fixed now:** the unscaled versions of these exact signals have already been
seen out of sample, so this OOS window is contaminated. Strategy 3 can reach at most
the **watch** tier; only forward data can make it a candidate.

## Strategy 4: funding filter on trend (`trend_funding`)

Strategy 1 with its final parameters, plus: a coin's weight is 0 while its trailing 3-day
mean Hyperliquid funding rate, annualized, is above F (funding known with a 1-day lag).
Grid: F ∈ {20%, 40%, 60%} → 3 trials. Funding data starts 2023-05/06, so there is no
walk-forward: F is the best net Sharpe on 2024. It is judged on the same tiers, and is
reported next to strategy 1 to show whether the filter adds anything.

## Decision (per strategy, from the framework)

- **Retire:** OOS net return ≤ 0, Sharpe < 0.5, or OOS return ≤ 0 with costs ×2.
- **Candidate:** not retired, and budget max drawdown ≤ 15%, and max drawdown ≤ half the
  max drawdown of equal-weight buy-and-hold of the six coins over the OOS window, and
  longest time below a previous peak ≤ 182 days.
- **Watch:** otherwise.

Candidates and watches go to shadow in chorus-howl. Going live follows a forward-test
pre-registration modeled on breakout v2 (≥ 3 weeks of shadow).

Reported regardless: in-sample walk-forward, per-coin results, costs ×2, buy-and-hold,
exposure, turnover, the 2025-10-10 crash and the Binance hack windows.
